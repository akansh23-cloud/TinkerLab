# This file is the AUTHORITATIVE dependency manifest for the Python function at
# apps/web/api/index.py. It deliberately replaces the previous pyproject.toml.
#
# Why: Vercel's Python builder resolves dependencies with uv. When a project
# contains a pyproject.toml WITHOUT a uv.lock, uv is selected and can complete

# boots, fails on `import fastapi`, and Vercel returns a platform-level HTTP 500
# whose body is HTML — which the frontend can only report as "Request failed (500)".
#
# A lone requirements.txt has no such ambiguity. Do not reintroduce a pyproject.toml
# here unless a committed uv.lock accompanies it.
