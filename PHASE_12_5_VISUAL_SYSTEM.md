# Phase 12.5 — Premium TinkerLab Visual System

This release rebuilds the product presentation around the Mission Control, Virtual Experiment Lab, and evidence-backed decision-story visual language.

## What changed
- Premium dark command-center shell with persistent scientific navigation.
- Mission Control dashboard driven by existing project, deployment, readiness, and flagship portfolio APIs.
- Top-level Virtual Lab mission selector.
- Dark industrial styling for furnace, dielectric, mechanical rigs, controls, evidence state, and deterministic decision rationale.
- Existing scientific backend contracts, PASS/FAIL/UNKNOWN semantics, and ADVANCE/REJECT/HOLD policy are unchanged.
- No AI, Gemini, or Jarvis dependency was added.

## Deployment
Deploy exactly like Phase 12.4: Vercel Root Directory `apps/web`; existing Neon and optional Materials Project environment variables remain unchanged.
