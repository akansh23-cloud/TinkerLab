# Phase 2 Scope

## Implemented

- Phase-1 project workflow preserved.
- Material identifiers/aliases and conservative identity resolution.
- Structured composition with redaction-safe components.
- Process/material state records.
- Source providers and immutable source-record snapshots.
- Expanded evidence and bibliographic citation entity.
- Typed observation condition sets.
- Multiple observations per material/property.
- Condition-aware deterministic selection with rationale.
- Property-specific conflict detection and curator preference.
- Organisation-private material/import scoping seam.
- JSON/CSV preview + transactional idempotent import.
- Material Explorer, Passport v2, Observation Inspector and Import Center.

## Explicitly deferred

Candidate generation, retrieval/mutation search, ML property prediction, model training, DFT, MD, CALPHAD, HPC, Bayesian/evolutionary optimisation, active learning, patent search, lab automation, manufacturing/economic scoring, production auth/SSO, billing, Kubernetes and vector search.
