# Phase 5 Scope — Autonomous Virtual Experiment Brain

Phase 5 adds bounded, deterministic, uncertainty-aware virtual optimization over Phase-3 hypotheses using Phase-4 model predictions.

## Included

- project-scoped `VirtualExperimentCampaign` envelopes;
- explicit objective/model pinning and hard-constraint model policies;
- zero-persistence campaign preview;
- bounded synchronous iterations;
- Phase-4 prediction orchestration in batches;
- robustly feasible / uncertain / robustly infeasible classification;
- conservative multi-objective vectors;
- deterministic non-dominated sorting;
- three transparent policy descriptors;
- parent selection with inspectable components;
- bounded mutation through Phase-3 search-space semantics;
- duplicate detection, child fingerprinting, lineage and typed change records;
- immutable iteration/evaluation/Pareto/decision records;
- explicit stop reasons and reproducibility checksums;
- Virtual Experiment Lab UI and two-objective Pareto visualization;
- a synthetic generic-polymer two-objective demo.

## Excluded

No DFT, molecular dynamics, CALPHAD, ML force fields, finite-element solver, HPC scheduling, physical laboratory request/result, synthesis protocol, robotics, experimental-learning loop, patent search, novelty claim, industrial viability scoring, supplier orchestration or model retraining is implemented.

A Phase-5 virtual evaluation is not evidence and does not create `MaterialPropertyObservation` rows.
