# Scientific Integrity — Phase 3

The principal invariant is:

> **A candidate hypothesis is a proposal, not evidence.**

Code/test guarantees include:

- generated/manual hypotheses are not inserted into the canonical `materials` table;
- hypothesis generation creates zero `MaterialPropertyObservation` rows;
- project property constraints for hypotheses evaluate to `UNKNOWN` when independent evidence/prediction is absent;
- baseline observations are not copied, averaged or inherited;
- structural screening is not converted into a performance score;
- known materials continue through Phase-2 evidence selection/conflict logic;
- no fake global AI/replacement score is produced;
- seed values remain explicitly synthetic demonstration fixtures.

Phase 4 may introduce explicit predictions, but those must carry model version, applicability and uncertainty rather than masquerading as experimental evidence.

## Phase 4 — prediction integrity

A model prediction is not a measurement, literature value, supplier value, computational physics result or experimental validation. Predictions are persisted only in `PropertyPrediction`.

All numeric predictions require an uncertainty method and prior applicability assessment. Out-of-domain, unsupported or incomplete targets receive no numeric value. Known applicable evidence is never silently overwritten.

The seeded predictor is explicitly synthetic and demo-only. Its metrics validate software plumbing, not real material performance.

## Phase 5 — virtual-evaluation integrity

A virtual campaign consumes predictions; it does not upgrade them into evidence. The invariant is:

> **VIRTUAL EVALUATION — MODEL-BASED; not a physical experiment or physics simulation.**

Code/test guarantees include:

- campaign execution creates zero `MaterialPropertyObservation` rows;
- optimizer consumes `PropertyPrediction` records rather than model coefficients;
- uncertainty intervals survive into feasibility and objective vectors;
- UNKNOWN/OOD/incomplete values are never counted as hard PASS;
- incomplete objective predictions do not receive a normal Pareto vector;
- mutation is constrained to the Phase-3 search space and approved rules;
- children remain `CandidateHypothesis` and inherit no material-property observations;
- structural validity is not interpreted as material performance;
- Pareto labels are campaign-local, not global-optimum claims;
- the added density predictor remains unmistakably synthetic/demo-only;
- no physics, physical experiment or laboratory validation claim is generated by Phase 5.


## Phase 6 — simulation integrity

The Phase-6 invariant extends the same principle to a third origin:

> **A physics simulation result is computational evidence, not measured evidence and not a model prediction.**

Code/test guarantees:

- a simulation run creates **zero** `MaterialPropertyObservation` and **zero** `PropertyPrediction` rows;
- `simulation_results` carries `operational_status` and `scientific_status` as separate columns, so a
  clean exit code is never recorded as convergence;
- a `SimulationPropertyEstimate` exists only for a `converged` result with a valid unit mapping; the
  `/simulation/integrity` endpoint reports `estimates_from_non_converged_results`, which must be zero;
- an unavailable provider, a missing registered artifact or an inadequate representation produces a
  typed refusal with reasons, never a fabricated number;
- a formulation-level composition is structurally refused by DFT and MD routes: atoms, topology and
  force-field mappings are never inferred from component names;
- route previews persist nothing;
- completed Phase-5 campaign evaluations are byte-identical before and after simulation runs;
- simulated values enter a project comparison only under an explicit, versioned selection policy;
- the software-validation fixture is labelled `SOFTWARE VALIDATION SIMULATION FIXTURE` everywhere it
  appears and its output is dimensionless by construction, so it cannot be read as a physical energy.


## Phase 7 — industrial integrity

A fourth claim class joins the separation guarantee:

> **Industrial evidence is not scientific evidence.** Cost, supply, environmental and regulatory
> records never become property observations, model predictions or simulation results, and none of
> those become industrial evidence.

Code/test guarantees:

- an industrial assessment creates zero observations, zero predictions and zero simulation results;
- missing evidence yields UNKNOWN or INSUFFICIENT_EVIDENCE, never zero and never a pass;
- monetary figures on different currency, currency-year or basis are never silently converted —
  USD 5/kg is not evaluated against a EUR 10/kg limit;
- regulatory status does not transfer between jurisdictions;
- an unrecorded manufacturing compatibility is not compatibility;
- elemental composition comes only from a declared structural representation, never from a name;
- contradictory records are both retained and reported as CONFLICTING_EVIDENCE; the newer one does
  not win and nothing is averaged across the contradiction;
- a hard constraint failure is never averaged away by other dimensions passing;
- a composite score requires a declared methodology, excludes unknown dimensions rather than scoring
  them zero, and stays flagged as partial;
- a completed assessment is immutable: new evidence supersedes it and the earlier conclusion remains
  explainable exactly as it was made;
- a converged physics simulation never satisfies the experimental-validation dimension.


## Phase 8 — reasoning integrity

- a property is not carried across a demonstrably different material state, however favourable the
  number would be;
- structural identity derives from an actual structural representation; with none recorded there is
  no identity, rather than a formula-derived stand-in (diamond and graphite are both carbon);
- stated composition ranges are never collapsed to a midpoint;
- processing-history order is part of state identity;
- evidence origins are reported separately and never averaged; a governing value is chosen by
  declared priority, which reports rather than merges;
- an out-of-domain prediction and an unconverged simulation are displayed but never used to satisfy
  a requirement;
- a value with no recorded state is used but flagged, and the limitation is surfaced as an explicit
  assumption;
- an absent value stays UNKNOWN — not a soft pass, not a soft fail;
- an objective reports PARTIAL, never PASS, because ranking against no threshold is not passing;
- disagreeing sources produce CONFLICTING_EVIDENCE with both retained;
- a reasoning edge without evidence or a source reference is refused;
- chain confidence is the weakest link, never a product or an average;
- all statuses are computed from structured data before any language is generated, and no language
  model can change them.


## Phase 9 — experimental integrity

- a protocol version is immutable; editing creates a new version and a run pins the checksum it used;
- every measurement traces to a sample, and one that does not is marked INCOMPLETE_PROVENANCE rather
  than counted;
- instrument calibration is never assumed, and claiming it requires a date and a reference;
- raw and processed artifacts stay distinguishable;
- an experimental measurement never overwrites a prediction or a simulation — all three are retained
  and compared, and disagreement is reported rather than averaged;
- two conflicting measurements are both kept; the later does not supersede the earlier, and the
  state becomes INCONCLUSIVE;
- "validated" is never used for simulation-only support;
- unimplemented experimental designs are refused rather than faked;
- experiment priority is not called expected value of information, because no such mathematics is
  implemented;
- no endpoint generates materials autonomously, orders experiments or operates hardware.
