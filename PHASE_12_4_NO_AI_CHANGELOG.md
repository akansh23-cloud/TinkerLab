# Phase 12.4 — No-AI Virtual Lab changelog

Generative AI has been removed from the Phase 12.4 Virtual Experiment Lab.

## Removed
- Gemini API integration.
- Gemini environment variables.
- Lab Copilot UI, API routes, schemas, services and tests.
- AI connection/status indicators and free-text copilot prompts.

## Retained
- Thermal/furnace industrial visualization.
- Dielectric-breakdown visualization.
- Mechanical-loading visualization.
- Interactive 3D specimen.
- Operator-defined visualization setpoints.
- Evidence-linked PASS / FAIL / UNKNOWN states.
- Deterministic ADVANCE / REJECT / HOLD / TEST decisions.
- Deterministic Decision Rationale with evidence gaps and next action.
- Materials Project integration as an optional scientific data source.
- Neon/Postgres persistence and the existing Vercel hybrid runtime.

## Boundary
A virtual visual cycle does not create a scientific measurement. The authoritative outcome continues to come from stored evidence, approved calculations/simulations, physical-validation records and deterministic decision rules.
